# AI 见闻录

分享有用的 AI 资源，也记录值得关注的作者、文章和视频。

学习 AI、做项目的过程中，我会接触到不少工具、教程和讨论。建这个资源库，是想把它们整理得更方便查找：除了链接，也写上它有什么用、适合谁、可以从哪里开始看。自己以后用得上，也分享给有同样兴趣的朋友。

如果刚开始了解 AI，可以先看中文课程和基础视频；如果已经在做产品，可以直接找原型制作、模型比较和 Agent 相关资料。目录会随着每周整理逐步补充。

首版整理于 **2026-10-15**。[第 001 期](editions/001-2026-10-15.md)收录了一些帮助理解模型、上手使用和判断结果的资料，其中也有较早发布的课程与文章，方便从基础开始阅读。

## 怎样持续整理

每周整理一次，补充值得收录的内容，也检查链接是否失效、介绍是否过时。适合长期查阅的资源放进分类目录，新收录的内容记在当期更新里；有值得分享的再加，不凑条数。

欢迎提交推荐：给出原始链接，再说一句它帮你完成了什么。纠错、替代入口和实际使用反馈也很有价值。具体写法见[收录与更新说明](CONTRIBUTING.md)。
