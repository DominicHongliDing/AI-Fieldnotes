# AI 见闻录

整理 AI 资源、值得关注的人，以及想留着慢慢看的文章和视频。

我在学习和做 AI 项目时，会遇到不少有用的工具、教程和讨论。收藏以后，往往又想不起它能解决什么问题。所以建了这个小库，把入口和推荐理由一起留下，也分享给有同样需要的人。

这里会逐步补全常用场景。刚开始了解 AI，可以从中文课程和基础视频看起；已经在做产品，可以直接找原型、模型比较和 Agent 相关资料。

## 首版收录

**30 个网站与资源入口 · 7 位作者或频道 · 5 个视频与 3 篇文章**

首版整理于 **2026-10-15**。[第 001 期](editions/001-2026-10-15.md)先从“理解模型、开始使用、判断结果”这条线选资料，包含早期课程和基础文章，不作为本周新闻。

网站条目写明用途、适合谁和如何开始。视频保留原始链接与作者，注明推荐依据；没有完整观看的内容只做观看导引。核对过官网介绍，不等于已经亲自测试过产品。

## 怎样持续整理

计划每周整理一次，新增一小组有用的内容，并修正改名、失效和过时的条目。长期资源留在分类目录，近期内容进入当期记录；没有足够值得收录的内容时，不凑条数。

欢迎提交推荐：给出原始链接，再说一句它帮你完成了什么。纠错、替代入口和实际使用反馈也很有价值。具体写法见[收录与更新说明](CONTRIBUTING.md)。
